# Site Tubarun

Site institucional da Tubarun — Academia, Assessoria Esportiva, Eventos e Loja.

- `index.html` — página única, responsiva, sem dependências de build
- `assets/img/` — fotos do site
- `vercel.json` — cache longo para as imagens

## Publicar
Importe este repositório na Vercel (Framework: **Other**, sem comando de build, diretório de saída: raiz).

## WhatsApp
No fim do `index.html`, procure `var WHATSAPP = ''` e coloque o número com DDI e DDD, só dígitos (ex.: `5541999999999`).
